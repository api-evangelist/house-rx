# House Rx

> House Rx is a healthcare technology company that equips independent specialty and community clinics to run in-house, medically integrated dispensing pharmacies. Its cloud platform supports the full specialty-medication workflow — prior authorization, financial counseling, fulfillment, patient outreach, real-time analytics, and EHR integration. House Rx does not publish a public developer API; this profile captures company identity, security posture, and public web properties.
